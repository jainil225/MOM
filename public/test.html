Each journey below states its goal, where it starts, each user action with what AiX Track does in response, the expected outcome, and what happens when something goes wrong.

Journey 1

Sign in

GoalGet into AiX Track securely
WhoNew and returning customers
Starts atLogin page, or a referral link shared by a friend

Steps

User doesAiX Track does
1Opens AiX TrackShows the login page if the user is not signed in
2aClicks Continue with GoogleOpens Google sign-in, then returns the user to the app
2bOr enters a Work emailEmails a 6-digit login code
3Enters the codeChecks it and signs the user in
4First sign-in onlyCreates the account and adds the joining bonus and free trial minutes. If the user came from a referral link, records the referrer
5—Opens the Home screen. The login stays active for 30 days on that device
Outcome: user is on Home, signed in, with their minutes and credits visible in the top bar.
If something goes wrong
  • Wrong or expired code: an error is shown. The user can request a new code or use ← Change email.
  • Too many code requests in a short time: requests are paused for a few minutes.
  • Code email not received: the user checks spam, or signs in with Google instead.
Journey 2

Record a meeting live

GoalCapture a meeting as it happens
WhoCustomer attending the meeting
Starts atHome → Record Live

Steps

User doesAiX Track does
1Clicks Record LiveShows the minutes the user can record with their current balance
2Confirms recording consentRecords that consent was given before starting
3Allows microphone access in the browserStarts recording and shows a running timer
4Holds the meetingSaves the audio to the server in small pieces every few seconds, so a dropped connection does not lose the meeting. Warns the user before they leave the page
5Clicks stopCompletes the recording and moves on to meeting options (Journey 4)
Outcome: the full recording is saved and ready to be turned into a MOC.
If something goes wrong
  • Microphone blocked: the app explains how to allow it from the browser's lock icon.
  • Microphone unplugged or used by another app: the app asks the user to reconnect it and try again.
  • Browser closed or connection lost mid-meeting: the saved pieces can be recovered and processed from Home.
  • Balance runs low: the app shows how many minutes are left before recording starts.
Journey 3

Upload a recording

GoalTurn an existing audio or video file into a MOC
WhoCustomer with a saved recording
Starts atHome → Drop your recording here

Steps

User doesAiX Track does
1Drops a file on the upload area or chooses oneAccepts common audio and video formats, including long meetings of several hours
2Sets meeting options (Journey 4) and confirms consentRecords consent before processing
3Waits on the progress screenUploads the file in parts with a progress bar, so large files and slow connections work
4—Moves on to the balance check and processing (Journey 5)
Outcome: the file is received in full and processing starts.
If something goes wrong
  • Unsupported or damaged file: a clear error asks for another file.
  • Login changed during upload: the user is asked to log in again and retry.
  • Recording longer than the maximum allowed length: it is refused before any charge.
Journey 4

Set meeting options

GoalGet a MOC shaped for this meeting
WhoCustomer, before processing
Starts atOptions panel on Home

Options

OptionWhat it changes
LanguageAuto-detect, or a set language: English (India), Hindi, Hinglish, Gujarati, Marathi, Bengali, Kannada, Malayalam and others
Meeting type / formatFor example Client Conversation, Board Conversation, Audit / Compliance, Client Advisory / Virtual CFO, Finance Review, HR / Recruitment. Sets the structure of the MOC
Speaker namesLabels who said what and names people where the recording makes it clear. Uses minutes at twice the standard rate
ProjectFiles the meeting under a client or engagement (Journey 10)
Tags and categoryMakes the meeting easy to filter later in Records
Extra instructionsQuick choices such as "Focus on financial decisions", "Include all GST / tax points", "Highlight client commitments", "Formal board minutes style", or free text for this meeting only
Outcome: the MOC will follow the chosen format, language and focus. Saved defaults from Profile are filled in automatically.
Journey 5

Minutes, credits and buying a pack

GoalKnow the cost and pay only for what is used
WhoCustomer
Starts atAutomatically before processing, or the credits badge in the top bar
flowchart LR
  A[Recording length
after long silences removed] --> B[Free minutes used first]
  B --> C{Still minutes to pay?}
  C -- No --> F[Processed free]
  C -- Yes --> D{Enough credits?}
  D -- Yes --> G[Processed, credits deducted
after the MOC is ready]
  D -- No --> E[Pricing page
Starter, Growth or Enterprise]
  E --> P[Pay securely] --> Q[Credits added] --> G

Steps

User doesAiX Track does
1Starts processingMeasures the recording after removing long silences, so the user does not pay for silence
2—Uses free minutes first, then credits. Standard: 1 credit per minute. With speaker names: 2 credits per minute
3If short of credits: opens Pricing and picks a packOpens a secure payment window
4PaysConfirms the payment and adds credits once. A payment is never credited twice
5—Deducts credits only after the MOC is produced and shows the new balance
Outcome: the user sees the cost before any charge, and every credit added or used appears in their order and credit history.
If something goes wrong
  • Not enough balance: processing stops before anything is charged, with a link to buy credits.
  • Payment window closed or payment failed: no credits are added and nothing is charged by AiX Track. The user can try again.
  • Speaker naming fails for a recording: the MOC is still produced and only the standard rate is charged.
Journey 6

Processing and reviewing the MOC

GoalGet an accurate MOC that the user has checked
WhoCustomer
Starts atProgress screen, then the MOC view

Steps

User doesAiX Track does
1WaitsShows progress through: preparing audio → transcribing → writing the MOC
2—Links the meeting to the user's earlier meetings and open actions, so follow-ups are recognised
3Reads the MOC draftShows the Executive Summary, Attendees, Agenda, Points Discussed, Agreed Directions / Decisions, Action Plan (owner, due date, priority), Information and Pending Tracker, and Next Meeting with proposed agenda
4Edits any section: adds an attendee, decision, agenda item or action item, corrects names and datesSaves the changes
5Optional: Regenerate or re-run speaker namesWrites a fresh MOC from the same recording
Outcome: a reviewed MOC, saved in Records. The MOC is an AI-prepared draft: the user checks names, figures, dates and decisions before sharing.
If something goes wrong
  • The writing step fails after transcription: the transcript is saved as a draft so the user can regenerate without recording again.
  • Recording has no clear speech: the app says so instead of producing an empty MOC.

WhoCustomer; recipients do not need an account

Choices

User doesAiX Track does

Emails the MOCDrafts an email with the MOC, which the user reviews and sends

Steps

User doesAiX Track does

Journey 10

Organise meetings into projects

GoalGroup meetings by client or engagement
WhoCustomer
Starts atProjects page

Steps

User doesAiX Track does
1Clicks + New Project, enters a project name, description and project contextCreates the project. The project context helps the AI understand every meeting in that project

Journey 11

Profile, defaults and Google Drive storage

GoalSet defaults once and choose where recordings are kept
WhoCustomer
Starts atProfile page

Steps

User doesAiX Track does
1Sets Display Name, Firm Name, Prepared By, Service Line and Default MOC FormatUses these on every new MOC and Word export
2Clicks Connect Google Drive and allows access on Google's screenCreates an "AiX Track Recordings" folder in the user's Drive
3Continues using the app as normalAfter each MOC is saved, moves the recording into the user's Drive and frees space on AiX Track. Playback still works from Records
4Optional: DisconnectStops moving new recordings. Files already in Drive stay there
5Copies their referral linkGives bonus credits to the friend and to the user once the friend joins
6Optional: Delete My Account Permanently, then confirmsDeletes the account and its meetings
Outcome: MOCs carry the firm's details automatically, and recordings stay in the customer's own Drive if they choose.
If something goes wrong
  • User declines Google's permission: nothing changes and recordings stay with AiX Track.
  • Drive is full or access was removed: recordings stay with AiX Track and Profile shows the problem until it is fixed.
Journey 12

Admin

GoalRun the service: users, credits, cost and MOC quality
WhoAiX Track admins only
Starts atAdmin pages (hidden from customers)

Tasks

Admin doesAiX Track does
Changes a user's role or adjusts creditsApplies it and records the change in the credit history
Reviews usage and cost per user and per meetingShows minutes processed, cost and balances, and can email a usage report
Edits the master MOC instructions and activates a versionUses the active version for all new MOCs. Older versions are kept
Opens the log for any MOCShows exactly what instructions were used, to explain a result
Checks orders, storage and service healthLists payments, disk use and alerts
Outcome: the service runs within budget, and any MOC result can be explained.
